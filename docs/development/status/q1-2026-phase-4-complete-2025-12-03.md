## Integration Architecture

### Data Flow

```
Recipe (.bb file)
  ↓
RecipeExtractor.extract_from_content()
  ↓
extract_class_dependencies()
  ↓
for each inherited class:
  ├─ ClassRegistry.load_class(class_name)
  │    ├─ Find .bbclass file in search paths
  │    ├─ parse_class_file() with Python evaluation
  │    ├─ extract_inherited_classes() for recursive loading
  │    └─ Cache ClassDefinition
  │
  └─ ClassRegistry.get_all_class_dependencies(class_name)
       └─ Return flattened dependencies from inheritance tree
```

### Configuration

**BuildOrchestrator:**
```rust
let mut extractor = RecipeExtractor::new(ExtractionConfig {
    extract_tasks: true,
    resolve_providers: true,
    resolve_includes: true,
    resolve_inherit: true,
    extract_class_deps: true,        // Enable ClassRegistry
    class_search_paths: vec![        // Poky class directories
        "meta/classes-recipe",
        "meta/classes",
        "meta-poky/classes",
    ],
    ..Default::default()
});
```

**ClassRegistry initialization:**
```rust
// In RecipeExtractor::new()
let class_registry = ClassRegistry::new(config.class_search_paths.clone())
    .with_variables(config.default_variables.clone());
```

## Lessons Learned

### What Worked Well

1. **Incremental development:** Build, test, integrate, validate
2. **Backward compatibility:** Hardcoded fallback prevented breaking changes
3. **Early validation:** Testing with real Poky data caught integration issues
4. **Statistics tracking:** Visibility into parsed vs hardcoded rates

### Challenges Overcome

1. **Mutability requirements:** ClassRegistry.load_class() needs &mut self
   - **Solution:** Changed RecipeExtractor methods to &mut self
   - **Impact:** Minimal - only affected internal API

2. **Configuration discovery:** extract_class_deps wasn't enabled initially
   - **Solution:** Added explicit flag in BuildOrchestrator
   - **Impact:** 0 parsed classes → 109 parsed classes

3. **Search path setup:** Needed multiple class directories
   - **Solution:** Added both classes-recipe/ and classes/ paths
   - **Impact:** Coverage increased from ~60% to 83%

### Unexpected Discoveries

1. **High parse success rate:** 83% dynamic parsing exceeded expectations
2. **Low overhead:** +2.5s on first build, 0s on cached builds
3. **Recursive inheritance:** More common than expected (20+ classes)
